# 来源分类型，集合由来源推导

每个技能都记录它的来源。一个来源在库里占一行，从同一来源入库的技能共用这一行。

来源分三种类型：GitHub 仓库、压缩包 URL、本地目录。每种类型的定位信息形状不同，分别是仓库和 ref、URL、目录路径。我们统一用"类型标记 + 一段 JSON"来存，不按类型分别建列或建表。以后新增一种类型，只需加一个枚举值和它的读取逻辑。

集合不单独存储。集合就是"来源相同的技能"，直接由来源推导出来。本地目录也算一个来源。做入库预览的是一个目录时，来源就是这个目录；做入库预览的是一个技能文件夹时，来源是它的上一级目录，这样从同一目录先后入库的技能同属一个集合。上一级目录是用户主目录、读不出，或读出的候选里没有这个文件夹时，来源仍是这个技能文件夹本身。

更新时，库会重新读取来源，重新发现其中的技能，再从中找回要更新的那一个，而不是依赖上次记下的路径。

skills.sh 只用来搜索和发现技能，不算一种来源。搜索结果必须经过入库预览才能入库，入库时记录的是它背后实际的 GitHub 仓库。skills.sh 的安全审计也只用于展示：用户查看某个候选时按需查询，结果不入库，不随同步带走，也不作为能否入库的条件。

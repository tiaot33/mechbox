# 确认状态与待定事项

这一节记录每条规则被项目维护者(GitHub 账号 tiaot33)确认到什么程度。规则本身在品牌手册和各组件的说明里;这里只列还要确认的。

## 标记的意思

| 标记 | 意思 | 怎样对待 |
| --- | --- | --- |
| 〔已确认〕 | 维护者明确说过或点过头 | 照做,不改 |
| 〔提议〕 | 原会话提出,维护者看过预览,没有单独确认 | 照做,等维护者确认 |
| 〔暂定〕 | 交接文档里留空的值,做这份设计系统时先填上 | 照做,等维护者确认;确认前可以整项替换 |
| 〔照搬〕 | 从现有代码提取,原样保留 | 照做;数值以代码为准 |

得到确认后,把标记改成〔已确认〕。要改条款或增加例外时,向项目维护者提出,由维护者决定。生效日期:2026-11-15。

## 2026-11-15 看过实际效果后确认的方向

改造完在 macOS 的原生窗口里看过浅色和深色,维护者确认了下面五条。它们标〔已确认 2026-11-15〕;和它们冲突的旧条款已经改掉。

- 绿只给动作和选中,不表示任何状态。
- 提醒要分级:同名、来源里的文件改动、本地文件改动这些按优先级分等级,不同等级样子不同(浅色、深色分别设计)。提醒不要太强调:用小圆点,占地小的时候只画圆点;要重新安装的圆点也按提醒的级别上色。
- 按钮照 macOS 设置页的样子(灰底、没有边框);不用方块的白按钮和淡绿按钮;一排按钮里要分得出主次。
- 一个列表里每一行一样高,文字多了不撑高;左栏、设置页的行高也各自统一。
- 一栏里文字只有一条左边线、一条右边线。
- 按钮、输入框、搜索框、下拉框、分段选择统一成一种圆角,不用胶囊形;胶囊形只给开关和计数。
- 底板上不套带投影的卡片,分区之间用线和间距分开;投影只留给浮在内容上面的表面。
- 列表的节标题和技能名拉开,不再同样加粗。
- 浅色和深色分开设计:浅灰底的小控件在浅色下发脏,在深色下没问题。

## 提议的条款

下面的条款标为〔提议〕,还没有单独确认。

- 3.2 绿色的值:浅色 `#15803d`,深色 `#30d158`。
- 三级提醒的归级(哪个提醒算哪一级)、圆点的形状(空心圈、实心点、带晕的实心点)和色值:严重 `critical` 浅色 `#d92d20`(字 `#b42318`)、深色 `#ff5a4f`(字 `#ff8a80`);注意 `warn` 浅色 `#d97706`(字 `#92400e`)、深色 `#ff9f0a`(字 `#ffb340`);提示 `info` 浅色 `#2f7fd6`、深色 `#5eb0ff`,字不上色。一处有几条提醒时只画最重的一级。
- 按钮分四档(主要、强调、普通、轻)和各处按钮归到哪一档;强调按钮是灰底加半粗的绿字。
- 控件一律 24 px 高、圆角 7 px;技能列表的行 32 px,侧栏的行 28 px,设置页的行 40 px。
- 设置页的分区照 macOS:标题在上,下面一块浅灰底的圆角区域。
- 3.4 选中的行用淡绿底:浅色 12%,深色 16%。
- 3.5 底色、边框、分隔线、悬停的底和实心强调的值。
- 4.1 主要档和禁用档的色值(次要档和标注档已确认)。
- 4.5 文字放在别的底色上时按那个底色重算。
- 6.2、6.3 现有提醒的归级;三级提醒的标签都带图标。
- 中性的小标签(带 × 的小标签、组的整组开关)的样子:浅色下透明底加细边(黑 14%),深色下白 10% 的浅底、不描边。
- 组名在列表里不套标签的框:只是 `muted-foreground` 的字,不加图标。
- 计数:浅色下没有底,深色下白 7% 的浅底;用无衬线的等宽数字。
- 作用域栏里项目不在这台机器上时只画橙色的警示图标,文字在悬停提示里。
- 7.3、7.4 确认删除用实心强调;文字链接只用于去别的地方。
- 主要按钮不叠渐变;普通按钮细边的深浅(浅色黑 26%)。
- 8.3 控件高度。分段选择里选中的一段圆角 5 px。
- 列表顶部的摘要直接排在底板上;弹窗里的面板用 `border` 的边。
- 9.1、9.2、9.3 毛玻璃只留给五种表面;其余改成不透明;左栏和作用域栏透出系统材质,不铺淡彩渐变。
- 第 11 节各组件「怎样变」的写法。
- 第 13 节四处没有例外的地方具体改成什么样:认不出的 Agent 用灰色;关系图用线型区分;语法高亮改成灰度;文件差异里新增用绿色、删除用灰色加删除线。

## 核对时发现的事

- 禁用档 `subtle` 在 `fill` 和 `primary-soft` 上是 2.2:1 到 2.7:1,低于它在 `tile` 上的 3:1。禁用的项不给悬停的底;选中的行里出现禁用的控件时会碰到。
- 开关关着的槽 `track` 在 `tile` 上是 1.5:1(浅色)和 2.4:1(深色)。开和关靠圆钮的位置和槽的颜色一起表示。
- 深色下,关着的开关和「经别处装上」的灰色开关,槽的颜色接近,只靠圆钮的位置分开。

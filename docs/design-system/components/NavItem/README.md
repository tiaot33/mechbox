# NavItem

左栏和作用域栏的导航行。

- 行高统一 28 px:顶层的行、分节标题、分节里的集合和组、右栏的 Agent 和项目都一样高;圆角 `radius-control`。行首的图标或箭头在同一列,各行的字在同一条线上;行尾的计数右对齐〔已确认 2026-11-15〕。
- 平时用 `foreground-secondary`;悬停用 `fill` 底加 `foreground`。
- 选中:顶层的页面(技能库、更新、设置)用 `fill` 的灰底加半粗;集合、组、Agent 用淡绿底 `primary-soft` 加半粗的 `foreground`(原来是淡蓝底、蓝字)。
- 集合名、组名都用无衬线(5.2)〔已确认 2026-11-15〕。
- 行尾的计数见 Count:浅色下只是灰色的数字,深色下带半透明的浅底。Agent 行上「要重新安装」的提醒图标按最重的那一处的级别画。
- 左栏默认宽 `sidebar`(210 px),作用域栏 `scope-bar`(270 px)。两栏透出窗口背后的系统材质(9.3),样例里画在 `tile` 上。

你提供:图标、文字、计数、是否选中。

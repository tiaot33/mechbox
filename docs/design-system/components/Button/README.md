# Button

按钮照 macOS 设置页的样子:一块没有边框、没有投影的灰底(`control`),圆角 `radius-control`(7 px),高 24 px,字在正中;按下时缩到 97%。不用带边框的白方块,也不用淡绿的方块〔已确认 2026-11-15〕。

按轻重分五档〔提议〕:

| 档 | 样子 | 用在哪 |
| --- | --- | --- |
| 主要 `primary` | 实心 `primary` 底、`on-primary` 字,没有渐变和投影 | 一屏或一个弹窗里最主要的那一个动作,只有一个(7.2) |
| 绿胶囊 `pill` | 实心 `primary` 底、`on-primary` 字,胶囊形(`radius-pill`),不带图标 | 只给「更新」和「入库」:节标题、更新列表、技能详情上的「更新」「全部更新」(不写数量);行首的「入库」「更新」小一号,高 20 px〔已确认 2026-11-15〕 |
| 强调 `accent` | 和普通按钮一样的灰底,字是半粗的绿色(`on-primary-soft`) | 一块区域里最要紧的动作(技能详情的「安装」) |
| 普通 `default` | 灰底、`foreground` 的字;悬停、按下时底变深 | 常用但不抢眼的动作 |
| 轻 `ghost` | 没有底、`foreground-secondary` 的字,悬停时铺 `fill` | 顶栏、列表行内,以及不常用的动作 |

- 一排按钮里要分得出主次:最多一个主要、绿胶囊或强调,其余按常用程度用普通或轻〔已确认 2026-11-15〕。
- 弹窗底部的确认按钮(如更新计划里的「更新 N 个」)仍是主要按钮,和旁边的「取消」同一个形状,不用胶囊。
- 两种外观:浅色下灰底是黑 6%,深色下是白 10%,都没有边框和投影〔已确认 2026-11-15:浅色和深色分开设计〕。
- 破坏性不是另一档:平时用普通或轻;只在确认删除的弹窗里,确认按钮用实心强调(`solid` 底、`on-solid` 字),不得用绿色(7.3)。
- 文字链接(`primary` 色的字)只用于去别的地方,如「去入库」。「不感兴趣」「跳过」「重新安装」「看差异」是动作,用轻按钮(7.4)。
- 高度 24 px,和输入框、搜索框、下拉框、分段选择一样高(8.2);只放图标的按钮是 24 px 见方,行内的小图标按钮 20 px。
- 字用 `body`(13 px 常规),强调按钮半粗。中文字形在行框里偏下半个像素,按钮底下垫 1 px 把字托回正中〔提议〕。
- 进行中:文字留着占位、上面盖一个转圈,按钮宽度不变;完成时转圈合成对勾(7.5,照搬)。
- 禁用:字用 `subtle`,底不变;主要按钮整体降到 45% 不透明度(照搬)。焦点:3 px 的 `primary-soft` 光圈。

你提供:文字(动词开头)、可选的图标、哪一档、是否进行中或完成。

# Button

按钮分三档轻重:主要(实心绿)、淡绿(`primary-soft` 底、`on-primary-soft` 字，给节标题上的「更新」这类列表里反复出现的动作，不写数量)、普通(浮起的 `control` 面加 `shadow-control`,悬停、按下时面变深)、轻(没有底和边框、次要档的灰字)〔已确认 2026-11-15〕。

样子参照 macOS 原生控件：胶囊形、略微浮起、按下时缩到 97%;主要按钮顶上一道淡亮线(`shadow-primary`)。

- 一屏或一个弹窗里,主要按钮只有一个(7.2)。大多数按钮用普通;顶栏和列表行内用轻。
- 破坏性不是第四档:平时用普通按钮;只在确认删除的弹窗里,确认按钮用实心强调(`solid` 底、`on-solid` 字),不得用绿色(7.3)。
- 文字链接(`primary` 色的字)只用于去别的地方,如「去入库」。「不感兴趣」「跳过」「重新安装」「看差异」是动作,用轻按钮(7.4)。
- 高度 `control`(28 px)或 `control-sm`(24 px),胶囊形;和输入框、下拉框排在一行时高度必须相同(8.2)。
- 字用 `body`(13 px 常规)。现有的 500 字重不在两档字重里,这里取常规〔暂定〕。
- 进行中:文字留着占位、上面盖一个转圈,按钮宽度不变;完成时转圈合成对勾(7.5,照搬)。
- 禁用:字用 `subtle`,底不变;主要按钮整体降到 45% 不透明度(照搬)。焦点:3 px 的 `primary-soft` 光圈。

你提供:文字(动词开头)、可选的图标、哪一档、是否进行中或完成。

# Badge

提醒分三级,另有不算提醒的平常信息。提醒没有底色和边框,只是一个 12 px 的实心小图标,地方够时后面跟一行字〔已确认 2026-11-15:提醒要分级,不同级别用不同图标;6 px 圆点看过实际效果后改成图标;具体归级和色值〔提议〕〕。

| 级 | 图标 | 后面的字 | 现有的提醒 |
| --- | --- | --- | --- |
| 严重 `critical` | 红色的圆里一个叉(`xmark.circle.fill`) | `critical-fg`,半粗 | 文件夹不在了;项目不在这台机器上;操作失败;审计没通过 |
| 注意 `warn` | 橙色的三角里一个叹号(`exclamationmark.triangle.fill`) | `warn-fg` | 更新里改动了脚本;版本落后要重新安装;同名;更新会换掉你的修改;成员被跳过;审计有警告 |
| 提示 `info` | 蓝色的圆里一个 i(`info.circle.fill`) | `foreground-secondary`,不上色 | 被手动改过(用户自己的修改);有你的修改;来源里已删除;库里有几个同名的 |
| 更新 `update`(不是提醒) | 主题绿(`primary`)的圆里一个向上的箭头(`arrow.up.circle.fill`) | `foreground-secondary` | 有新版本;在 app 外更新到了作者的新版;本地目录来源在目录里改过 |
| 可能改名 `rename`(不是提醒) | 主题绿的圆里一个向右的箭头(`arrow.right.circle.fill`) | `foreground-secondary` | 可能改名(要用户确认是不是同一个技能,和有新版本分开) |
| 平常 `plain` | 没有图标 | `muted-foreground` | 已是最新;最新;「随组安装」「来自全局」这类说明 |

- 字用 `caption`(11 px)。图标 12 px,和字隔 6 px;三级形状不同,不只靠颜色分。里面的符号镂空,透出底下的颜色,浅色深色共用一个形状、只换颜色。
- 三种样子:带文字的标签(`Badge`:图标加字);只有图标(`AlertIcon`,占地小的地方:作用域栏、列表行里跟在说明文字后面的);单独的图标(`MarkIcon`,给自己排版的地方,如作用域栏的 Agent 行和 Notice)。`AlertIcon` 的 `labeled` 是列表一行的状态列:图标后面写最要紧的一条,还有别的写 +N。
- 只有图标时,鼠标停住用提示显示文字和补充说明(可拖动的行上原生的 `title` 不出现,所以用 Tooltip);提示里的每一条同时留在 DOM 里给读屏,两处是同一份。
- 一处有好几条提醒时只画一个图标,按最重的一级;提示里从重到轻逐条列出。列表一行的状态列里更新、可能改名也合进这一个图标(严重、注意在前,更新其次,提示最后)。
- 提醒能直接做一件事时(有新版本:打开更新计划),图标是一个按钮:能用键盘聚焦,有焦点圈,回车或空格触发。
- 浅色下颜色压深一些,深色下提亮,见 `tokens.json`〔已确认 2026-11-15:浅色和深色分开设计〕。
- 颜色只表示级别,不表示别的:绿不用在提醒上。
- 组名不是提醒:列表里技能名后面只是 `muted-foreground` 的字。技能详情里的组是带 × 的小标签,见 Chip〔提议〕。

你提供:文字、它属于哪一级、地方小不小(小就只画图标)、补充说明(可选)。

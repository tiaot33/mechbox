# Badge

状态标签分三档,靠轻重区分,不靠色相(6.1)。

| 档 | 样子 | 现有的状态(6.2) |
| --- | --- | --- |
| 必须处理 | 较深的灰底(`foreground` 12%)、`foreground` 的半粗字,必须带图标(6.3)〔已确认 2026-11-15〕 | 更新里改动了脚本;被手动改过;文件夹不在了;项目不在这台机器上;需要重新安装;操作失败 |
| 要处理 | `fill` 的浅灰底、`foreground` 的字,不描边〔已确认 2026-11-15〕 | 有新版本;可能改名;同名;来源里已删除 |
| 平常 | `muted-foreground` 的字,没有边框和底色 | 已是最新;最新;未安装;日期;组名;「直接安装」「随组安装」这类标记 |

- 字用 `caption`(11 px),圆角 `radius-control`。
- 不用实心黑底和黑色描边：一屏里有很多标签时，黑块黑框太刺眼〔已确认 2026-11-15〕。
- 不得用绿色表示「已是最新」「已完成」(3.3)。
- 「必须处理」的图标是 `assets/Icons/alert.svg`〔暂定〕。

你提供:文字和它属于哪一档。

# Badge

提醒分三级,另有不算提醒的平常信息。提醒不抢眼:没有底色和边框,只是一个 6 px 的小圆点,地方够时后面跟一行字〔已确认 2026-11-15:提醒要分级,不要太强调,用圆点;具体归级和色值〔提议〕〕。

| 级 | 圆点 | 后面的字 | 现有的提醒 |
| --- | --- | --- | --- |
| 严重 `critical` | 红,实心点外面一圈 `critical-halo` 的淡晕 | `critical-fg`,半粗 | 文件夹不在了;项目不在这台机器上;操作失败;审计没通过 |
| 注意 `warn` | 橙,实心点 | `warn-fg` | 被手动改过;更新里改动了脚本;版本落后要重新安装;同名;更新会换掉你的修改;成员被跳过;审计有警告 |
| 提示 `info` | 蓝,1.5 px 的空心圈 | `foreground-secondary`,不上色 | 有新版本;可能改名;来源里已删除;有你的修改;库里有几个同名的 |
| 平常 `plain` | 没有圆点 | `muted-foreground` | 已是最新;最新;未安装;日期;「直接安装」「随组安装」这类标记 |

- 字用 `caption`(11 px)。圆点 6 px,三级形状不同,不只靠颜色分。
- 三种样子:带文字的标签(`Badge`:圆点加字);只有圆点(`AlertDot`,占地小的地方:列表的行、作用域栏);单独的圆点(`Dot`,给自己排版的地方,如「装在哪」一列和作用域栏)。
- 只有圆点时,鼠标停住用提示显示文字和补充说明(可拖动的行上原生的 `title` 不出现,所以用 Tooltip);提示里的每一条同时留在 DOM 里给读屏,两处是同一份。
- 一处有好几条提醒时只画一个圆点,按最重的一级;提示里从重到轻逐条列出。
- 提醒能直接做一件事时(有新版本:打开更新计划),圆点是一个按钮:能用键盘聚焦,有焦点圈,回车或空格触发。
- 浅色下颜色压深一些,深色下提亮,见 `tokens.json`〔已确认 2026-11-15:浅色和深色分开设计〕。
- 颜色只表示级别,不表示别的:绿不用在提醒上。
- 组名不是提醒:列表里技能名后面只是 `muted-foreground` 的字。技能详情里的组是带 × 的小标签,见 Chip〔提议〕。

你提供:文字、它属于哪一级、地方小不小(小就只画圆点)、补充说明(可选)。

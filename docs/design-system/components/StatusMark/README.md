# StatusMark

状态圈 Spinner / StatusMark:进行中是转动的弧;结束时弧合成整圈,合拢后画出对勾或叉。

- 对勾和叉都用主要档的文字色 `foreground`(原来对勾是绿、叉是红)。绿色不表示「已完成」(3.3)。
- 两个尺寸:11 px(和 13 px 的字一起用,笔画 3)和 14 px(顶栏标题旁,笔画 2.2)。样例里 14 px 的笔画按 2 画。
- 时长照搬:外圈合拢 300 ms,再用 260 ms 画出对勾或叉;转一圈 1.1 s(10.2)。
- 系统要求减少动态效果时,转圈改成呼吸式的淡入淡出,对勾直接出现(10.3)。

你提供:状态(running / done / failed)和尺寸。

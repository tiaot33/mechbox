# Segmented

分段选择:一组按钮,选中的一段垫着一块 `control` 面。

- 外框圆角 `radius-control`(7 px),和同一行的按钮一样〔已确认 2026-11-15:看过实际效果后改〕;`control` 的灰槽(和普通按钮同一种灰),不描边,内边距 `space-2`;总高 24 px,和按钮一样高。
- 选中的一段:`segment` 面加 `shadow-control`(浅色下白底加很淡的细边和一点投影,深色下浅一些的灰),字用 `foreground`;没选中的用 `foreground-secondary`。里面那一段比外框小一圈,圆角 5 px。
- 换选中项时滑块用不回弹的弹簧滑过去,320 ms;系统要求减少动态效果时直接跳过去(10.2、10.3)。
- 选中不用绿色:这是在几个并列的选项里切换,不是选中一行。

你提供:选项(值和文字)、当前值。

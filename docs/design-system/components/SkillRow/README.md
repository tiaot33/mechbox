# SkillRow

技能行:列表里的一个技能。

- 技能名用 `body-strong`(13 px 半粗无衬线)加 `foreground`,描述用 `small`(12 px)加 `muted-foreground`(5.4);装在哪用 `foreground-secondary`,全局一律写出是哪几个 Agent;要重新安装的用 `foreground`,不加粗(原因在最后一列)。
- 行高固定 32 px(列表窄、每行两层时 48 px);节标题 36 px,节与节之间隔 16 px,列表要紧凑,每一行一样高:每一格只有一行字,放不下就截断;多出来的说明(同名的后果、符号链接指向哪里、库里同名的几个各装在哪)收进图标或文字的悬停提示〔已确认 2026-11-15〕。
- 最后一列是状态(要处理的事):提醒和更新只写最要紧的一条,图标加一句话,还有别的写 +N,鼠标停住时逐条列出;有新版本、可能改名时点它打开更新计划。没有要处理的事时空着;作用域页上随组安装、来自全局的写一句灰字,直接安装是常态不写。名字后面不画图标,一行只有这一个提醒图标〔#357〕。
- 「装在哪」一列只写字,不画图标;有要重新安装的地方时字用 `foreground`,原因在最后一列。
- 组名不套标签的框:技能名后面只是 `muted-foreground` 的字,不加图标;在几个组里时写第一个组名加「+N」〔提议〕。
- 列表的节标题(集合名、组名)用 `heading`(15 px 半粗),比技能名大一档;节标题下面的线用 `border`,行与行之间用 `row-line`〔已确认 2026-11-15:看过实际效果后改〕。
- 节标题的图标在行首勾选框那一列(鼠标移上去或勾了技能以后换成这一节的勾选框),节标题的名字、技能名、页面顶部的摘要和分段选择左对齐在同一条线上;行尾的链接和节标题的收起箭头右对齐〔已确认 2026-11-15〕。
- 选中的行用淡绿底 `primary-soft`。
- 开关:直接安装的是绿色开着;随组安装或来自全局的是淡一些的绿色开着,一眼看得出装着。

你提供:技能名、描述、状态、开关。

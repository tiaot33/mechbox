# ScopeSummary

列表顶部的摘要:作用域页和项目页最上面的一条,写这里有几个技能、Agent 目录、各项计数和每个组的整组开关。更新页的更新列表也是这个样子。

- 不是浮起的卡片:直接排在底板上,没有底色、边框和投影,和下面的列表之间隔一条 `row-line` 的线〔已确认 2026-11-15:看过实际效果后改〕。
- 第一行:那句话在左,用 `heading`(15 px 半粗);这一页的动作(全部重新安装、照着其他 Agent 装、全部入库)都在右边排成一排,用 24 px 的普通按钮。作用域摘要里没有主要按钮。
- 第二行:目录和各项计数从左到右写成一行,用 `caption` 加 `muted-foreground`。
- 计数:数字用半粗的 `foreground-secondary`,后面的字用 `muted-foreground`。有需要重新安装的技能时，这一项换成提醒的标签(圆点加字),按最重的那一处的级别上色。
- 目录是标识符,用 `mono-caption`;前面的小标题用 `caption`。
- 组的整组开关:高 22 px,样子是中性的标签(`tag` 底、`tag-border` 边)。没装的是空心圆点、`foreground-secondary` 的字;装上的圆点是 `primary` 的绿色实心、字用 `foreground`,不加粗。和开关一样,绿表示开着〔提议〕。
- 整组开关后面的「装了几个 / 共几个」用 `caption` 加等宽数字,不用等宽字体。

你提供:那句话、目录、各项计数、组和它们的状态。

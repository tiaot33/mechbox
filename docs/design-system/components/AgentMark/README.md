# AgentMark

Agent 图标:一个小方块里画按名字认出的品牌图标。

- 品牌图标保留原来的颜色,这是全系统两处例外之一(第 13 节)。底用 `mark`,深色下仍是浅色,纯黑的 logo 也看得清。
- 图标文件在 `assets/Agents/`,按 Agent 的名字取;图标占方块的 78%。
- 认不出的 Agent 画机器人 `assets/Icons/bot.svg`,用 `subtle` 的灰色。不再按代码取一个颜色(第 13 节,〔提议〕)。
- 默认 14 px,圆角 4 px(照搬);按场合改尺寸。
- 项目里共用一个目录的几个 Agent 叠着画,最多 3 个,每个外面描一圈 1.5 px 的 `panel`。

你提供:Agent 的名字(用来认图标)和尺寸。
